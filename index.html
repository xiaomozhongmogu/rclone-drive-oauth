rclone-drive

A personal Google Drive OAuth application used with rclone to access and synchronize the owner's files between their computer and Google Drive.

This application is intended for the owner's personal use. It uses Google's authorization process to grant rclone access to the owner's Google Drive.

This website provides application information only. It does not ask for Google passwords, OAuth credentials, or file uploads.

Privacy policy

This is an independent personal configuration and is not an official Google or rclone service.
