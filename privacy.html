Privacy policy

Last updated: October 29, 2026

rclone-drive is a personal OAuth application used by its owner with rclone to access and synchronize their Google Drive files.

Data access and use

After the owner authorizes access through Google, rclone uses Google Drive file contents and metadata to perform the file operations selected by the owner, such as listing, downloading, uploading, and synchronizing files. Data passes between the owner's computer and Google Drive as required for those operations.

Storage and sharing

OAuth credentials and tokens are stored in the owner's local rclone configuration. Downloaded or synchronized files are stored in the locations chosen by the owner. This personal application does not operate a separate data collection server, sell Google user data, or use Google user data for advertising.

This website

This static information website does not request Google account passwords, collect OAuth tokens, or receive Drive files. It contains no analytics scripts, advertising, or sign-in forms. It is hosted on GitHub Pages, whose hosting service may process ordinary web request information under GitHub's privacy statement.

Control and revocation

The owner can stop using rclone, remove locally stored credentials and files, and revoke this application's access through Google Account connections. Revoking authorization does not automatically remove copies of files already synchronized to the owner's computer.

Scope of this policy

This policy describes the owner's personal rclone configuration. Questions can be directed to the developer using the support email shown on the Google OAuth consent screen. This policy will be updated if the application's use or data handling changes.
